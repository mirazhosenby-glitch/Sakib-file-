# FEATURES (STRICT STEPS)

### **User Registration:**
Step 1 → Detect `/start` command via webhook
Step 2 → Check if `telegram_id` exists in `users` table
Step 3 → If not, insert new user record with referral tracking from `/start <ref_id>` payload
Step 4 → Send **"Welcome to Earning Zone BD"** message with Main Menu Reply Keyboard

### **Force Join Verification:**
Step 1 → Fetch active channels/groups from `channels` table
Step 2 → Call `getChatMember` API for each channel against the user
Step 3 → If not joined, block bot usage and show join buttons (Inline Keyboard, opens channel directly in Telegram) + "🔄 Recheck" button
Step 4 → On Recheck, re-verify and unlock bot if all joined

### **Task Completion:**
Step 1 → List active, non-expired tasks from `tasks` table via Inline Keyboard buttons
Step 2 → On task click, show task details with a verification button (opens link/channel directly inside Telegram)
Step 3 → Verify completion based on `verification_method` (channel join, bot start, link click)
Step 4 → Check `task_completions` table to block duplicate claims
Step 5 → Credit reward to user balance and insert completion record

### **Withdrawal Request:**
Step 1 → User selects network (TRC20/BEP20) via Inline Keyboard and enters wallet address as plain text message
Step 2 → Validate wallet address format
Step 3 → Check balance against min/max withdrawal limits from `settings`
Step 4 → Insert into `withdrawals` table with status `pending`
Step 5 → Admin approves/rejects/marks paid via Admin Panel
Step 6 → Notify user of status change via bot message

### **Referral System:**
Step 1 → Generate unique referral link using bot username + `telegram_id` (format: `https://t.me/<bot_username>?start=<telegram_id>`)
Step 2 → On new user registration via referral link, insert into `referrals` table
Step 3 → Credit referral bonus to referrer's balance
Step 4 → Notify referrer of new referral via bot message

### **Daily Bonus:**

Step 1 → Check `last_bonus_claim` timestamp for user
Step 2 → If 24 hours have passed, allow claim via "🎁 Daily Bonus" menu button
Step 3 → Credit configured bonus amount and update timestamp
Step 4 → Log claim in `transactions` table

### **Admin Broadcast:**
Step 1 → Admin composes message (text/photo/video/document) with optional inline buttons via Admin Panel
Step 2 → Fetch all active user `telegram_id`s from `users` table
Step 3 → Loop and send via Telegram Bot API with rate-limit delay
Step 4 → Log success/failure counts in `broadcast_logs` table

Follow steps EXACTLY and do not add anything outside these steps.
